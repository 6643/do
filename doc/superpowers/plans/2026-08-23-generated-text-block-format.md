# Generated Text Block Formatting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Replace ad-hoc multiline structured-text concatenation with one
shared indentation-aware helper without changing generated bytes.

**Architecture:** Add a leaf `src/build/codegen_text.zig` module that only
depends on `std`. Static and formatted multiline templates both pass through
the same normalizer; callers choose an explicit base indentation. Existing
single-line append operations and non-structured text remain on their current
paths.

**Tech Stack:** Zig 0.16.0, `std.ArrayList(u8)`, `std.fmt`, existing compiler
and WIT/Component regression harness.

**Spec:** `doc/superpowers/specs/2026-08-23-generated-text-block-format-design.md`

## Global Constraints

- Preserve generated WAT/WIT/Do/metadata/probe bytes exactly.
- Treat only ASCII spaces as removable indentation; preserve tabs and other bytes.
- Preserve unrelated dirty changes; do not reset, clean, checkout, commit, or push.
- Do not migrate user text, diagnostics, JSON/LSP payloads, or single-line fragments.
- Use named format arguments for migrated multi-argument templates.
- Run `./src/build/test/run_tests.sh` before handoff.

- [x] **Step 2: Implement `append_block`.**

Scan the template once to calculate the minimum leading ASCII-space count among
non-empty LF-delimited lines, then scan again to append each line with common
indent removed and `base_indent` spaces added. Do not add spaces to blank lines.

- [x] **Step 3: Implement `append_fmt_block`.**
